## 🇧🇷 Português (Brasil)

### 📖 Sobre o Projeto
O **Site Profissional** (`siteprofissional.pro`) é uma plataforma web estática de alta velocidade hospedada via **GitHub Pages**, focada no desenvolvimento de sites institucionais, landing pages e soluções web de alto rendimento para empresas, empreendedores e profissionais liberais.

Este repositório conta agora com uma estratégia técnica completa de **SEO Local** e **GEO (Generative Engine Optimization)** voltada para a cidade de **Ourinhos/SP**, incluindo dados estruturados (Schema.org), Open Graph, sitemap dinâmico e proteção de ambientes de desenvolvimento.

### 🚀 Destaque Tecnológico: Google Antigravity
Todo o ciclo de engenharia, planejamento, auditoria semântica, validação e governança de código deste projeto foi acelerado e potencializado pelo ecossistema **Google Antigravity**, aplicando padrões rigorosos de desenvolvimento responsável e alta performance.

#### 🤖 Agentes de IA e Especialistas Envolvidos:
- **`orchestrator`**: Coordenação executiva e alinhamento do ciclo de desenvolvimento.
- **`project-planner`**: Decomposição técnica e plano de execução em fases.
- **`seo-specialist`**: Arquitetura de metadados, JSON-LD Schema.org, sitemap canônico e SEO local para Ourinhos/SP.
- **`frontend-specialist`**: Construção da landing page `/programador/` e da página `404.html` com design responsivo Mobile First.
